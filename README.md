## 📌 Proyecto destacado

### 📦 Sistema de inventarios y control de producción

Aplicación orientada a gestionar existencias, movimientos entre bodegas y el seguimiento de productos durante los procesos productivos.

**Funcionalidades:**

- Consulta y control de inventario.
- Transferencias y consumos de productos.
- Registro de productos mediante códigos de barras.
- Sesiones de escaneo y registro de órdenes.
- Consulta de movimientos e historial.
- Gestión de usuarios y permisos.

**Tecnologías:** Node.js, JavaScript, MySQL/MariaDB y API REST.
